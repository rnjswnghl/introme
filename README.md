# introme · T01

권주회의 관심사와 경험을 소개하는 한 페이지입니다.

## 목적
함께 배우는 동료와 협업 상대에게 관심사, 일하는 방식, 프로젝트 경험을 근거와 함께 소개합니다.

## 실행
별도 설치 없이 `python -m http.server 4173 --directory dist` 실행 후 http://localhost:4173 에서 확인합니다.
배포 대상은 dist/이며, 소스·기록은 이 저장소에서 관리합니다.

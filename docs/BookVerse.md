# BookVerse · 권주회의 역할과 결과

개인 프로젝트 기록에서 공개 가능한 내용만 정리한 자기보고 자료입니다. 실행 중인 서비스나 독립적인 제3자 검증 자료를 의미하지 않습니다. 당시 프로젝트는 미배포 상태입니다.

## 목적
사용자 맞춤형 도서 추천과 커뮤니티를 통해 독서 경험을 공유하는 웹 서비스.

## 01 책임감
- 상황: 개발 시작에 필요한 도서 데이터와 백엔드 기반이 필요했다.
- 행동: 팀장으로 알라딘 API 초기 데이터 구성·전처리, Django 백엔드 초기 구조 설계를 맡았다.
- 결과: 초기 데이터와 기능 개발을 위한 구조를 구성했다.

## 02 탐구와 구현
- 상황: 많은 책 중 관심 있는 책을 찾는 방법이 필요했다.
- 행동: 전체 도서 목록·상세 페이지, 카테고리 필터·검색, 저자·장르·랜덤 기반 추천을 구현했다.
- 결과: 목록 탐색, 상세 정보와 세 가지 추천 기능을 연결했다.

## 03 끈기와 협업
- 상황: 기능 추가 때마다 예상하지 못한 오류가 발생해 시간이 늘어났다.
- 행동: 참고 자료를 찾아 적용하고, 팀원과 파트를 바꿔 가며 버그를 해결했다.
- 결과: 목표 기능 대부분을 구현했고 UI 개선 필요성을 회고에 남겼다.

## 본인 담당 범위
팀장, 초기 데이터 구성·전처리, Django 초기 구조, 마이페이지, 지도, 도서 추천, 전체 도서 목록·상세 페이지, 일부 UI.

## 팀 기술과 결과의 한계
Django·Django REST Framework, Vue.js, SQLite, Git 등을 사용한 팀 프로젝트다. 팀 전체 기능을 개인 구현으로 주장하지 않는다. 전체 UI 미완성과 미배포 상태를 숨기지 않는다. 사용자 수·전환율·속도 개선 수치는 제공 자료에 없어 기재하지 않았다.

## 자료 처리
사용자가 제공한 자기소개 README와 기본 정보 문서의 프로젝트 회고를 재작성했다. 사적인 원문 링크와 제3자 이름·정보는 공개하지 않는다.

# T01 · 가을의 서재 리디자인

2026-09-11. 사용자가 정한 동양풍·가을·감성적 분위기·폴라로이드·적절한 애니메이션을 반영했다.

## 무엇을 어떻게 바꿨는가
- 제목: 나눔명조 Regular. 본문과 UI: Pretendard Variable v1.3.9. 정식 폰트와 OFL 라이선스를 자체 호스팅.
- 화면: 따뜻한 종이색·먹색·단풍색, 인장처럼 작은 이름표, 한글 세로쓰기, 책의 갈피처럼 세 경험을 배치.
- 이미지: 한옥 마당의 단풍, 창가의 책·찻잔·은행잎을 ImageGen으로 생성. 실제 촬영 사진이 아니며 화면에 AI 제작 표시.
- 폴라로이드 두 장이10~12초 주기로3~5px 움직임. 정지/다시 켜기 버튼, OS 움직임 줄이기, JavaScript 비활성 시 정지.
- 세 경험의 상황–행동–결과 및 근거 원문 유지. JavaScript가 없어도 상세 설명은 읽을 수 있게 개선.

## 2026-09-14 · 실제 전환형 폴더 탭과 프로젝트 근거
- 상단 파일 탭을 앵커 이동에서 `소개·프로젝트·관심·기록` 전환형 ARIA 탭으로 바꿨다. 활성 패널 한 개만 보이며 주소 해시로 각 패널을 직접 열 수 있다.

## 2026-09-14 · 채용용 문구와 프로젝트 정보 재정리
- GitHub의 채용용 프로필 가이드에서 소개를 짧게 쓰고, 대표 프로젝트를 빠르게 이해할 수 있게 설명하라는 원칙을 확인했다.

## 2026-09-15 · 실제 실행 화면과 트러블슈팅 분리
- 이전 포트폴리오 저장소에 보관된 네 프로젝트의 빌드 결과를 로컬 서버에서 실행하고, 한페이지·FocusMate·On-Wear·DALTOORI의 대표 화면을 직접 캡처했다.

- 기존 README와 커밋 조사에서 근거가 있던 사례만 유지했다. 접근할 수 없었던 공개 Notion 링크의 내용은 추정해 추가하지 않았다.
- 1366×768, 1920×1080, 390×844, 320×700에서 네 이미지 로드, 확대 dialog, 트러블슈팅 열기, 프로젝트 전환, 가로 넘침과 콘솔 오류를 검사했다.

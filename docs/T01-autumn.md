# T01 · 가을의 서재 리디자인

2026-09-11. 사용자가 정한 동양풍·가을·감성적 분위기·폴라로이드·적절한 애니메이션을 반영했다.

## 무엇을 어떻게 바꿨는가
- 제목: 나눔명조 Regular. 본문과 UI: Pretendard Variable v1.3.9. 정식 폰트와 OFL 라이선스를 자체 호스팅.
- 화면: 따뜻한 종이색·먹색·단풍색, 인장처럼 작은 이름표, 한글 세로쓰기, 책의 갈피처럼 세 경험을 배치.
- 이미지: 한옥 마당의 단풍, 창가의 책·찻잔·은행잎을 ImageGen으로 생성. 실제 촬영 사진이 아니며 화면에 AI 제작 표시.
- 폴라로이드 두 장이10~12초 주기로3~5px 움직임. 정지/다시 켜기 버튼, OS 움직임 줄이기, JavaScript 비활성 시 정지.
- 세 경험의 상황–행동–결과 및 근거 원문 유지. JavaScript가 없어도 상세 설명은 읽을 수 있게 개선.

## 브라우저 검사
- Edge의 새 컨텍스트에서1366×768,1920×1080,390×844,320×700 검사. 모두 가로 넘침0.
- 데스크톱 근거 하단756.89px /992.09px. 소개·경험·근거 첫 화면 노출.
- 두 폰트 loaded, 두 이미지 로드 성공. 로컬 실패 요청0, 콘솔/pageerror0.
- 세 경험과 모션 버튼 각각 클릭·Enter·Space 통과. Tab13개 초점 테두리 확인.
- OS 모션 설정 변경 반영, 독자가 직접 멈춘 상태 보존, 무스크립트 상세 본문 노출·사진 정지 확인.
- h1 1개, 제목 단계 건너뛰기 없음, 내부 앵커 모두 존재. 외부 링크2개 HTTP200.
- 실제 표시 텍스트 대비 최소4.65:1, 기준 미달0.
- 루트 글자 크기200% 스트레스 검사 가로 넘침0. 브라우저 확대 인증과는 구분한다.
- OS 설정 변경 이벤트가 비동기이므로 테스트는 버튼의 상태 변경을 기다린 뒤 검사한다.
- 캡처는 비교를 위해 움직임을 멈춘 상태로 저장했다. 실제 기본 화면은 OS가 허용하면 움직인다.

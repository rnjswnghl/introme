## 짧은 확인 방법

1. 어디로 가나요: 시크릿 창에서 https://introme-t08.vercel.app/#private 를 엽니다.
2. 세 단계 안에 무엇을 하나요: 00~03 공개 탭을 눌러 1번 소개 내용을 보고 → 04 비공개 탭을 누르고 → 주소창에 `/api/private`를 붙여 엽니다.
3. 무엇이 보이면 통과인가요: 공개 탭은 그대로 열리고, 04 탭에는 `여기부터 비공개 영역` 띠와 내용 없이 봉인된 세 칸만 보이며, `/api/private`는 `401 login_required`입니다.
4. 안 될 때는 무엇이 보이나요: 04 탭 위 상태 줄에 이유가 나옵니다(`서랍 저장소가 아직 연결되지 않았습니다`, `https 주소인지 확인`, `이 브라우저는 패스키를 지원하지 않습니다` 등). 서랍 내용은 어떤 경우에도 나오지 않습니다.

## AI와 내 판단 (본인 말로 확정)

1. AI에게 맡긴 일: 패스키 서버·화면 코드, 검증용 소프트웨어 인증기와 확인 스크립트, Vercel 배포 설정, 설명서 초안.
2. 내가 직접 판단한 일: (작성) 예) 1번 소개 페이지에 이어 붙이고 T07처럼 Vercel·Neon을 쓰기로 한 것, 패스키를 어디에 저장할지, 두 번째 패스키를 어떤 기기에 둘지.
3. AI 말을 따르지 않은 일: (작성) 없다면 왜 없었는지.
